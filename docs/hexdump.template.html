Offsets count octets from the start of each direction's byte stream. Each frame starts with the same 8-octet header: Length (2 octets), Type (1), Flags (1), and Request ID (4). After the header come exactly Length octets of payload. Inside a HEADERS payload, every field is a prefix octet, a 2-octet value length, and then the value.

That is a literal marker, the name's length, the name, the value's length and the value. If -g had been given, an extra frame such as 00 03 ba ff 00 00 00 01 "v2?" would sit in front of the request. Its type 0xBA is unassigned, so the server reads its 3 payload octets, discards them, and answers exactly as shown above.
